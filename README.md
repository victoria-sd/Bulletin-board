# Bulletin-board

Нам необходимо разработать интернет-ресурс для фанатского сервера одной известной MMORPG — что-то вроде доски объявлений. Пользователи нашего ресурса должны иметь возможность зарегистрироваться в нём по e-mail, получив письмо с кодом подтверждения регистрации. После регистрации им становится доступно создание и редактирование объявлений. Объявления состоят из заголовка и текста, внутри которого могут быть картинки, встроенные видео и другой контент. Пользователи могут отправлять отклики на объявления других пользователей, состоящие из простого текста. При отправке отклика пользователь должен получить e-mail с оповещением о нём. Также пользователю должна быть доступна приватная страница с откликами на его объявления, внутри которой он может фильтровать отклики по объявлениям, удалять их и принимать (при принятии отклика пользователю, оставившему отклик, также должно прийти уведомление). Кроме того, пользователь обязательно должен определить объявление в одну из следующих категорий: Танки, Хилы, ДД, Торговцы, Гилдмастеры, Квестгиверы, Кузнецы, Кожевники, Зельевары, Мастера заклинаний.

Также мы бы хотели иметь возможность отправлять пользователям новостные рассылки.

После заполнения полей регистрации, на почту придет **одноразовый код**, который необходимо ввести в форму ![image](https://github.com/user-attachments/assets/5b9ec2c6-4743-40e6-86a4-6462291d10c2)

В результате успешной авторизации откроется **приватная страница** пользователя с личными объявлениями и откликами на них, которые доступны по гиперссылке "**Отклики**", где можно принимать, удалять, а также фильтровать их. ![image](https://github.com/user-attachments/assets/b38bf942-023e-425a-aade-b078540175e9) ![image](https://github.com/user-attachments/assets/1e812aa7-d9f2-4c21-9456-b232b25a11e0)

После регистрации можно **добавить объявление** на главной странице через гиперссылку. ![image](https://github.com/user-attachments/assets/dc897ae7-098e-44fa-b39e-7af2efab1048)

Изменять можно только свои объявления перейдя по ссылке http://127.0.0.1:8000/ads/<int:pk>/update/. Отклик оставлять на этой же странице в специальной форме. ![image](https://github.com/user-attachments/assets/0d7f8988-44de-4a71-8273-7b741038fadc)

Письма на email приходят:
  1. При регистрации - одноразовый код;
  2. При получении отклика - автору объявления;
  3. При принятии отклика - автору отклика;
  4. При создании объявления - всем зарегестрированным пользователям.
